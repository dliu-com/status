How to test status.dliu.com

Two checks, both as a guest: the page opens, and the checker has run recently.

Functions

  • Status board: the page you're reading opens. If it's down, nobody can see the status.
  • Checker: the latest result is less than 30 minutes old (checks run every 15). If it's down, the board shows old results and says so.
Technical details: guest checks
FunctionRequestExpected
pagesGET https://status.dliu.com/200, text/html, body contains dl-footer
checkerGET https://status.dliu.com/data/status.json200, application/json, generatedAt within the last 30 minutes

Not tested

Nothing here needs a sign-in. The site has no /health endpoint: its only backend is the scheduled checker, which the second check covers.

Technical details: why there's no /health

The checker is a scheduled Lambda with no HTTP endpoint. /data/status.json is written by it at the end of every run, so its generatedAt shows the checker ran and could write to S3. The file is cached for 60 s.
